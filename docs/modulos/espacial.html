Estatística Espacial

Dados de Área (Moran, LM de Anselin, SAR/SEM/MDE) e Processos Pontuais (CSR, Ripley, Clark-Evans)

O módulo de Estatística Espacial do estatR cobre dois grandes domínios da análise espacial quantitativa:

  • Dados de Área (Areal Data) — Dependência geográfica entre regiões contíguas (municípios, estados, unidades censitárias): matrizes de vizinhança, Moran Global/LISA, diagnóstico LM de Anselin e modelos de regressão espacial (SAR, SEM e MDE).
  • Processos Pontuais (Point Pattern Analysis) — Análise do padrão de localização de eventos discretos no espaço (crimes, focos de doenças, árvores, ocorrências): testes de Aleatoriedade Espacial Completa (CSR), função K de Ripley, função G e teste de Clark-Evans.

Todos os gráficos utilizam ggplot2 com meu_tema(grade = "dupla") para manter o padrão editorial do pacote.

1. Matrizes de Vizinhança e Pesos Espaciais

A função matriz_vizinhanca() constrói matrizes espaciais padronizadas para polígonos ou coordenadas pontuais:

  • Contiguidade Geográfica (polígonos sf): "rainha" (vértices e arestas) e "torre" (apenas arestas compartilhadas).
  • Proximidade Métria / KNN: "knn" (\(k\) vizinhos mais próximos) e "distancia_inversa" (\(1 / d_{ij}^\alpha\)).
  • Seleção Automática: tipo = "auto" seleciona o melhor critério de vizinhança para o conjunto de dados.
library(estatR)

# Matriz por k vizinhos mais próximos padronizada por linha
W <- matriz_vizinhanca(
  dados        = dados_municipios,
  tipo         = "knn",
  k            = 5,
  coordenadas  = c("longitude", "latitude"),
  padronizacao = "linha"
)

2. Autocorrelação Espacial Global e Local (Moran e LISA)

A função analise_autocorrelacao() calcula o Índice I de Moran Global com teste de significância por permutações Monte Carlo e classifica as observações nos quadrantes locais de Moran (LISA):

  • Alto-Alto (Q1): Hotspots — regiões com valores elevados rodeadas por vizinhos com valores elevados.
  • Baixo-Baixo (Q2): Coldspots — regiões com valores baixos rodeadas por vizinhos baixos.
  • Alto-Baixo (Q3): Outliers espaciais — regiões com valores altos cercadas por vizinhos baixos.
  • Baixo-Alto (Q4): Outliers espaciais — regiões com valores baixos cercadas por vizinhos altos.
# Autocorrelação espacial e clusterização LISA
res_moran <- analise_autocorrelacao(
  dados          = dados_municipios,
  variavel       = pib_per_capita,
  coordenadas    = c("longitude", "latitude"),
  n_permutacoes  = 999
)

Gera no console a tabela editorial completa e o Diagrama de Dispersão de Moran com os quatro quadrantes destacados por cores analíticas.

3. Diagnóstico Metodológico: Testes LM de Anselin

Antes de estimar uma regressão espacial, a função teste_mult_lagrange_espacial() (ou teste_multiplicadores_lagrange_espacial()) aplica os quatro testes canônicos do Multiplicador de Lagrange de Anselin (1988) sobre os resíduos do modelo linear clássico (OLS/MQO):

  1. LM - Defasagem Espacial (Lag): Testa dependência na variável resposta (\(\rho\)).
  2. LM - Erro Espacial (Error): Testa dependência nos distúrbios (\(\lambda\)).
  3. LM Robusto - Defasagem: Robusto à eventual presença de erro espacial.
  4. LM Robusto - Erro: Robusto à eventual presença de defasagem espacial.
# Diagnóstico e recomendação automática do modelo
teste_mult_lagrange_espacial(
  pib_per_capita ~ educacao + saneamento,
  dados        = dados_municipios,
  matriz_pesos = W
)

A saída emite uma recomendação conclusiva padronizada no console com [✓], apontando se o pesquisador deve adotar o modelo clássico (OLS), SAR ou SEM.

4. Modelos de Regressão Espacial

Quando a dependência espacial é confirmada, o modelo clássico por MQO torna-se enviesado ou ineficiente. A função regressao_espacial() estima os principais modelos econométricos espaciais por Máxima Verossimilhança:

A. Modelo de Defasagem Espacial — SAR (modelo = "defasagem")

\[y = \rho W y + X \beta + \epsilon\] Captura processos de difusão, contágio e dependência direta entre as respostas das regiões vizinhas.

B. Modelo com Erro Espacial — SEM (modelo = "erro")

\[y = X \beta + u, \quad u = \lambda W u + \epsilon\] Corrige a autocorrelação nos resíduos decorrente de variáveis omitidas espacialmente estruturadas ou choques não observados.

C. Modelo de Durbin Espacial — MDE / SDM (modelo = "durbin")

\[y = \rho W y + X \beta + W X \gamma + \epsilon\] Inclui simultaneamente a defasagem espacial da variável dependente e os termos defasados das variáveis explicativas (\(W X\)).

# Ajuste do Modelo de Defasagem Espacial (SAR)
mod_sar <- regressao_espacial(
  pib_per_capita ~ educacao + saneamento,
  dados        = dados_municipios,
  modelo       = "defasagem",
  matriz_pesos = W
)

# Ajuste do Modelo de Durbin Espacial com busca automática de k vizinhos
mod_sdm <- regressao_espacial(
  pib_per_capita ~ educacao + saneamento,
  dados       = dados_municipios,
  modelo      = "durbin",
  k_vizinhos  = "auto"
)

5. Decomposição de Impactos Espaciais (LeSage & Pace)

Em modelos com defasagem espacial (SAR e Durbin), os coeficientes \(\beta\) não representam efeitos marginais diretos devido aos ciclos de retroalimentação espacial (feedback loops).

A função impactos_espaciais() decompõe a influência de cada regressor em três componentes fundamentais:

  • Impacto Direto: Efeito médio que uma alteração na variável explicativa de uma região exerce sobre ela mesma.
  • Impacto Indireto (Spillover): Efeito médio de transbordamento gerado sobre todas as regiões vizinhas.
  • Impacto Total: Efeito consolidado no sistema geográfico (Direto + Indireto).
# Decomposição de transbordamento (Spillover)
impactos_espaciais(mod_sdm)

6. Diagnóstico e Avaliação Polimórfica

O módulo de Estatística Espacial está plenamente integrado aos métodos unificados do estatR:

Análise Residual

Avalia a normalidade (Shapiro-Wilk) e testa a persistência de dependência espacial residual através do \(I\) de Moran:

analise_residual(mod_sar, grafico = TRUE)

Métricas de Ajuste

Exibe Pseudo-\(R^2\), RMSE, MAE, AIC, BIC, Log-Likelihood e autocorrelação residual:

metricas(mod_sar)

Comparação e Ranqueamento de Modelos

Permite comparar diretamente modelos OLS, SAR, SEM e MDE em uma única tabela com AICc, BIC e Pesos de Akaike:

comparar_modelos(
  OLS = mod_ols,
  SAR = mod_sar,
  SEM = mod_sem,
  SDM = mod_sdm,
  criterio = "aicc"
)

Parte II — Processos Pontuais (Point Pattern Analysis)

A análise de Processos Pontuais responde à pergunta fundamental: os eventos observados no espaço ocorrem de forma Aleatória, Agrupada (cluster) ou Regular (dispersa)? O estatR implementa os métodos clássicos com saídas ricas no console, testes formais com [✓]/[!] e gráficos editoriais em ggplot2.

Todas as funções aceitam:

  • coordenadas = c("x", "y") para especificar colunas manualmente ou detecção automática por nomes convencionais (x, y, lon, lat).
  • janela = "auto" para delimitar o retângulo de estudo automaticamente ou janela = c(xmin, xmax, ymin, ymax) para definição manual.

7. Teste de Quadrats — Homogeneidade de Primeira Ordem (CSR)

A função teste_quadrats() divide o domínio geográfico em uma grade de \(n_x \times n_y\) células e compara as contagens observadas em cada quadrat com a distribuição teórica de Poisson homogênea via teste Qui-Quadrado (\(\chi^2\)).

A Razão Variância/Média (VMR) complementa o teste formal:

  • \(VMR \approx 1\): compatível com aleatoriedade espacial completa (CSR).
  • \(VMR > 1\): superdispersão — eventos mais concentrados do que o esperado (Agrupamento).
  • \(VMR < 1\): subdispersão — eventos mais uniformes do que o esperado (Regularidade).

Parâmetro auto: nx = "auto" e ny = "auto" selecionam automaticamente a grade ótima para que a contagem esperada por célula atenda à regra de Pearson (\(E_i \ge 5\)), maximizando o poder do \(\chi^2\).

# Grade selecionada automaticamente
teste_quadrats(
  dados        = dados_ocorrencias,
  coordenadas  = c("longitude", "latitude")
)

# Grade manual 5×5
teste_quadrats(
  dados        = dados_ocorrencias,
  coordenadas  = c("longitude", "latitude"),
  nx           = 5,
  ny           = 5,
  janela       = c(xmin, xmax, ymin, ymax)
)

O gráfico exibe a distribuição de frequências dos quadrats (barras azuis) sobreposta à curva teórica de Poisson esperada (linha vermelha tracejada).

8. Teste de Clark-Evans — Agregação pelo Vizinho Mais Próximo

A função teste_clark_evans() compara a distância média observada entre cada evento e seu vizinho mais próximo (\(\bar{r}_A\)) com a distância teórica esperada sob aleatoriedade (\(\bar{r}_E = 1 / 2\sqrt{\lambda}\)).

O Índice de Clark-Evans (\(R = \bar{r}_A / \bar{r}_E\)) resume o diagnóstico numa única estatística:

  • \(R = 1\): Aleatório (CSR).
  • \(R < 1\): Agrupado (cluster) — atração mútua entre eventos.
  • \(R > 1\): Regular / Disperso — inibição ou competição espacial.

Parâmetro auto: correcao = "auto" aplica automaticamente a Correção de Borda de Donnelly (1978) quando a janela é retangular, corrigindo o viés de borda na estimativa de \(\bar{r}_E\).

# Com correção de borda automática
teste_clark_evans(
  dados       = dados_arvores,
  coordenadas = c("x", "y")
)

# Sem correção de borda
teste_clark_evans(
  dados       = dados_arvores,
  coordenadas = c("x", "y"),
  correcao    = "nenhuma"
)

O gráfico exibe a distribuição das distâncias ao vizinho mais próximo com as médias observada (verde) e teórica esperada (vermelho tracejado).

9. Função K de Ripley e L de Besag — Dependência de Segunda Ordem

A função funcao_k_ripley() (alias: funcao_ripley()) avalia a dependência espacial em múltiplas escalas de distância \(r\), superando a limitação dos testes de primeira ordem que não revelam em que escala o agrupamento ocorre.

A forma estabilizada de Besag: \[L(r) = \sqrt{\frac{K(r)}{\pi}} - r\] tem valor esperado \(L(r) = 0\) sob CSR, \(L(r) > 0\) indica agrupamento e \(L(r) < 0\) indica dispersão/inibição naquela escala.

Envelopes de Monte Carlo: A faixa cinza do gráfico representa o intervalo de confiança gerado por n_sim simulações de Poisson homogêneo. A curva observada fora dessa faixa constitui evidência de desvio em relação à CSR.

Parâmetros auto:

  • r_max = "auto" adota \(r_{\text{max}} = \frac{1}{4} \min(\text{largura}, \text{altura})\) — a recomendação clássica de Ripley para evitar distorções severas de borda.
  • n_passos = "auto" gera uma malha de 50 raios equidistantes.
# Com envelopes de Monte Carlo (padrão)
funcao_k_ripley(
  dados       = dados_ocorrencias,
  coordenadas = c("x", "y"),
  n_sim       = 99,
  nivel       = 0.95
)

# Com raio máximo manual e sem envelope
funcao_k_ripley(
  dados       = dados_ocorrencias,
  coordenadas = c("x", "y"),
  r_max       = 50,
  n_passos    = 100,
  envelope    = FALSE
)

O gráfico exibe a curva \(L(r)\) observada (linha azul), a referência CSR em \(y = 0\) (linha vermelha tracejada) e a faixa de simulação (cinza sombreado).

10. Função G — Distribuição Acumulada do Vizinho Mais Próximo

A função funcao_g_pontos() estima a distribuição acumulada \(G(r)\) das distâncias de cada evento ao seu vizinho mais próximo, comparando a curva empírica com a curva teórica de Poisson: \[G_{\text{CSR}}(r) = 1 - e^{-\lambda \pi r^2}\]

  • Curva observada acima do envelope: vizinhos mais próximos entre si do que sob CSR → Agrupamento.
  • Curva observada abaixo do envelope: vizinhos mais afastados do que sob CSR → Regularidade / Inibição.
  • Curva dentro do envelope: padrão consistente com CSR.
# Função G com envelope CSR
funcao_g_pontos(
  dados       = dados_ocorrencias,
  coordenadas = c("x", "y"),
  n_sim       = 99,
  nivel       = 0.95
)

O gráfico exibe a curva empírica \(G(r)\) observada (linha azul), a curva teórica de Poisson (linha vermelha tracejada) e a faixa de envelopes CSR (cinza sombreado).
